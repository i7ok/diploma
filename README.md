# От алгоритма к игре

Интерактивная веб-презентация для вводной встречи со студентами.

## Локальный запуск

Откройте `index.html` двойным щелчком в браузере. Интернет и установка библиотек не нужны.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий на GitHub, например `algorithm-game-presentation`.
2. Загрузите `index.html` и `README.md` в корень ветки `main`.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. После публикации ссылка обычно имеет вид `https://USERNAME.github.io/algorithm-game-presentation/`.

## Управление

- Стрелки влево/вправо, Page Up/Down — переключение слайдов.
- Home/End — первый/последний слайд.
- F / А — полноэкранный режим.
- Кнопки внизу — управление мышью. На слайде 4 первое действие «Далее» открывает ответ, а второе перелистывает слайд.

## Как показывать четыре «Змейки»

На слайде 12 показаны анимированные примеры диалогов и объясняется, зачем превращать алгоритм в игру. На слайде 13 запускаются четыре игры с автопилотом и есть вопросы для сравнения результатов. Порядок окон на обоих слайдах одинаковый. Нажмите на любое игровое окно, чтобы открыть игру на её GitHub Pages.

Исходные репозитории: [ChatGPT](https://github.com/i7ok/GPT_Snake), [Claude](https://github.com/i7ok/Claude_Snake), [Алиса](https://github.com/i7ok/Alisa_Snake), [ГигаЧат](https://github.com/i7ok/Giga_snake). Копии в `games/` используют оригинальные игровые поля и правила с добавленным управлением для демонстрации.

## Скриншоты игровых примеров

На слайдах 9–10 используются скриншоты из официальных галерей игр в Steam. Названия на слайдах ведут на страницы источников. Файлы хранятся в `assets/gameplay`.

## Публикация игры и шкала разработки

Слайд 14 показывает, как загрузить игру в репозиторий и опубликовать её через Settings → Pages.

Последние два слайда показывают условный семидневный цикл без ИИ и с ИИ. При перелистывании меняются границы между этапами. Следующее нажатие «Далее» раскрывает концовку фразы.

## Настройка

Слайды находятся в `index.html`, а код демонстрации игр — в папке `games`. Логотип и фотография хранятся локально в папке `assets`. Для запуска не нужны сборка или интернет.

## Оформление

Веб-оформление опирается на [фирменный стиль ИТМО](https://itmo.ru/ru/page/213/logotipy_i_firmennyy_stil.htm) и [публичные презентации университета](https://itmo.ru/ru/page/402/prezentacii.htm). Логотип взят с официальной страницы фирменного стиля.
