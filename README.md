# От алгоритма к игре

Интерактивная веб-презентация для вводной встречи со студентами (25–30 минут).

## Локальный запуск

Откройте `index.html` двойным щелчком в браузере. Интернет и установка библиотек не нужны.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий на GitHub, например `algorithm-game-presentation`.
2. Загрузите `index.html` и `README.md` в корень ветки `main`.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
5. После публикации ссылка обычно имеет вид `https://USERNAME.github.io/algorithm-game-presentation/`.

## Управление

- Стрелки влево/вправо, Page Up/Down — переключение слайдов.
- Home/End — первый/последний слайд.
- F — полноэкранный режим.
- Кнопки внизу — управление мышью.

## Как показывать четыре «Змейки»

На третьем слайде предусмотрено место для живой демонстрации. Откройте четыре своих игры в отдельных вкладках или добавьте ссылки прямо в `index.html`.

## Настройка

Все стили, слайды и JavaScript находятся в одном `index.html`. Нет зависимостей, сборки или внешних изображений.
